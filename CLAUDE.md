# My Portfolio Website

## What this is
My personal one-page portfolio website. Built with plain HTML, CSS and vanilla JavaScript only. No frameworks, no build tools. The site must work by simply opening index.html in a browser.

## Design guidelines
- Clean, minimal, modern and professional
- Generous whitespace, nothing cramped
- One cohesive colour palette, sans-serif typography
- Fully responsive: must look great on mobile and on desktop
- Subtle animations only, nothing flashy

### Current palette (implemented)
Matte black / charcoal dark theme with a single bright emerald accent:
- Background: `#121316` (main), `#0a0b0d` (contact/footer band)
- Card/elevated surfaces: `#1b1d22`
- Primary text: `#f3f1ea` (soft warm white)
- Secondary/body text: `#9aa2ac`
- Accent (button fills / dot fills): `#1e6f5c`, hover `#2f8b72`
- Accent glow (labels, tagline, timeline meta, dots — text-on-black): `#45d9ae`
- Hairlines/borders: `rgba(243,241,234,0.12)`
- Font: Manrope (Google Fonts)
